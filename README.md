# DevHub 6.0

Plataforma de estudos de programação em HTML, CSS e JavaScript.

## Novidades da versão 6.0
- Medalhas desbloqueadas por progresso real.
- Missão diária: concluir 2 aulas e resgatar +30 XP uma vez por dia.
- Desafios por nível: iniciante no nível 1, intermediário no nível 3 e avançado no nível 5.
- Recompensas únicas por marcos de nível (níveis 2, 3, 5, 7 e 10).
- Progresso anterior preservado no armazenamento local do navegador.

## Recursos mantidos
Cursos e aulas, XP, projetos, laboratório, anotações, perfil, tema, backup e PWA.

## Como executar
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` com a extensão Live Server.
4. Para instalar como aplicativo e usar o modo offline, use `localhost` ou hospedagem HTTPS.

## Dados e backup
O progresso fica salvo no `localStorage` do navegador/dispositivo. Use a função de backup do aplicativo antes de limpar os dados do navegador ou trocar de dispositivo.

## Arquivos
- `index.html`: estrutura.
- `style.css`: aparência.
- `app.js`: cursos, progresso, XP e gamificação.
- `manifest.json`: instalação PWA.
- `sw.js`: cache/offline.
- `icon.svg`, `icon-192.png`, `icon-512.png`: ícones.
